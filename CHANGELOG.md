## [2.0.0] - 2026-11-05

The first public release.

### Added

- Markdown and Org mode editing with callouts, tables, footnotes, LaTeX,
  Mermaid diagrams, wikilinks, block references and editable transclusions.
- A ⌘K palette that finds notes and then acts on them: open, refile, rename,
  quote into the current note, and batch actions on several notes.
- Live calc blocks with units, exact fractions, complex numbers, symbolic
  algebra, list comprehensions and inline plots.
- A native CSV spreadsheet, PDF and EPUB readers, Excalidraw canvases and
  Markdown diffs.
- Full-text search across notes and PDFs, with facet filters such as `ext:pdf`.
- A built-in MCP server with 27 tools, an action socket and the `nv3` CLI.
- Margin notes and questions you can leave for your AI agent, in Markdown, Org,
  plain text and PDF.
- Ten typographic themes, user themes in CSS, JavaScript plugins and a single
  config file.
- Automatic updates through Sparkle for signed releases.
